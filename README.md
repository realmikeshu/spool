# Spool

One desk for two kinds of research.

- **Social** reads public Reels, TikToks, and Shorts: the hook, the middle, and the ask.
- **Ads** reads the same kind of link, or pasted ad copy: offer, proof, audience, and what to test next.

Nothing is installed. History stays in the browser. Packs download to your computer.

```bash
npm install
npm run dev
```
